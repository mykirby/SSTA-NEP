# SSTA-NEP
This is the SSTA's nuclear electric propulsion projects storage and repo for all things related to the project. 

## Organization
This repository has 2 main sections:
1. Reactor Design
2. Thruster Design

Each section contains tutorials, examples, and working files for each group. All tutorials are Jupyter Notebooks, written in Python and Bash.

## External Codes
The project is currently conducted with open-source external codes, which are used for a variety of tasks. Below is a current list of codes used by each team:

<br>Reactor Design:
1. ANL's [Cardinal multi-physics coupling code]("https://github.com/neams-th-coe/cardinal") 
2. MIT's [OpenMC Monte-Carlo Neutronics code]("https://github.com/openmc-dev/openmc")
3. ANL's [NEKrs CFD code]("https://github.com/Nek5000/nekrs")
