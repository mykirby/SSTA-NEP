# Examples For Reactor Design
This is a folder storing code examples for different reactor design software
## What Goes Here
### 1. Helpful examples for concepts
Showing the basics of something, or showing a general way to approach problems with the software\
Ex: Basic NEKRS coupled CFD in cardinal, or how to couple multiple MOOSE modules at once with NEKRS in cardinal
### 2. Examples of interesting applications of software useful to the team
Files that show the power of a given software or software component, allowing the team to get a better idea of what they can do with the software\
Files that could be used as a basis to make more advanced, better models off of
## What Good Examples Look Like
### 1. Well-explained, clear comments
Explain well enough for someone to follow your thought process, but you don't need to explain every last step\
*There are some cases where explaining every last step is helpful, but generally it makes unnecessary clutter
### 2. Logically organized code
Don't jump all over the place, have a clear flow to it\
Ex: When making a car 3d model, first do all the parts to make a wheel, then all the parts to make the body, not make part of a wheel, then part of the body, switching back and forth randomly
### 3. Example output is provided
Give the expected output, so people can see what it outputs without needing to take the time to run it themselves
## Where To Put Examples
### 1. First sort by software
  Example: Cardinal code goes in the cardinal folder
### 2. Then by component
  Example: Cardinal Mesh code goes in the Mesh folder inside the cardinal folder
## Format
### 1. Create a unique subfolder for each example
### 2. Place in the example input and output files
  Be aware github has a 100mb file limit, so you may need to add a link to the output instead
### 3. Create a file called Info.txt in the folder
  a. Explain concisely what the example does \
  b. If any special instructions are needed to properly execute the example, note them in the file \
  c. If the output example file is too large, insert the link to its location in the SSTA one-drive
